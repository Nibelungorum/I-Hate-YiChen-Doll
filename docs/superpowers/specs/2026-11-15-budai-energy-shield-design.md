# Budai 动态能量层设计

## 目标

为 `budai` 玩偶增加一个跟随玩家身体动作的透明能量层。能量层包含持续流动的噪声和环形动态波纹，不包含护甲模型、胸口反应堆、护盾数值或伤害吸收逻辑。

玩家可以通过每个 `budai` 物品堆独立的 Data Component 控制能量层是否渲染。开关交互、动作栏反馈和 Tooltip 参照 `m_xm_` 玩偶的宇宙翅膀功能。

## 范围

- 仅修改 `budai` 的物品行为和玩家渲染。
- 不修改 `budai_see_u` 或其他玩偶。
- 不引入龙之研究的模块系统、能量系统、护盾容量和战斗逻辑。
- 保留 `budai` 从 `MeNetworkDollItem` 获得的 AE2 网络行为与 Tooltip。
- 增加中英文文本，不添加与功能无关的配置项。

## 物品与数据组件

新增持久化且网络同步的布尔组件 `BUDAI_SHIELD_VISIBLE`。物品没有该组件时视为 `true`，使已有物品默认显示能量层，无需数据修复。

新增 `BudaiDollItem extends MeNetworkDollItem`，并仅在 `ModItems.createDoll` 的 `budai` 分支使用：

- 手持玩偶右键时，在服务端反转组件值。
- 通过动作栏显示当前“能量层渲染”状态，开启为绿色，关闭为红色。
- 在父类 Tooltip 后追加当前状态，以及“手持右键切换能量层”的操作提示。
- 返回与服务端修改一致的交互结果。

## 玩家渲染

新增 `BudaiShieldLayer extends RenderLayer<AbstractClientPlayer, PlayerModel<AbstractClientPlayer>>`，在 `EntityRenderersEvent.AddLayers` 中为默认和纤细玩家模型注册。

每次渲染时：

1. 使用 `CuriosBridge.activeStacks(player, "budai")` 获取有效玩偶物品堆。
2. 仅当至少一个物品堆的 `BUDAI_SHIELD_VISIBLE` 为 `true`（缺失时默认 `true`）时继续。
3. 使用略微膨胀的玩家模型绘制能量层，复制父模型的姿态和肢体角度，使头、身体和四肢随玩家动作运动。
4. 不绘制任何额外护甲、宝石或反应堆部件。

能量层只负责视觉表现；卸下玩偶或关闭组件后直接跳过绘制，不增加服务端每 tick 的渲染状态逻辑。

## 动态波纹与渲染类型

新增独立的 Shader 和 `RenderType`，不复用宇宙翅膀的颜色、贴图遮罩或 Uniform，避免两个效果互相影响。

- 以红色透明能量为默认外观。
- Fragment Shader 根据纹理坐标计算径向距离，叠加多组随时间循环的环形波纹。
- 加入平滑噪声扰动，避免波纹呈现为规则静态圆环。
- 使用客户端游戏时间与 `partialTick` 更新 `Time` Uniform，保证帧间动画平滑。
- 使用双边绘制、透明混合和适当的深度写入策略，减少外层模型自身遮挡造成的缺面。
- 保留玩家受击 Overlay、环境光和雾效，使能量层符合场景渲染。

## 语言文本

在中英文语言文件中增加以下语义：

- 能量层渲染状态标签。
- 已开启与已关闭状态。
- 手持右键切换能量层的 Tooltip 提示。

物品交互与 Tooltip 共用同一组状态文本，避免显示不一致。

## 验证

1. 运行项目编译与检查任务，确认 Java、Shader 和语言资源没有错误。
2. 启动客户端，分别验证默认与纤细玩家模型的外层姿态和遮挡。
3. 验证佩戴 `budai` 时显示动态波纹，卸下后立即消失。
4. 验证手持右键能切换状态，动作栏和 Tooltip 同步更新。
5. 验证重新进入世界后开关状态保留，旧物品默认开启。
6. 验证 `budai_see_u`、`m_xm_` 和宇宙翅膀行为不受影响。
7. 在多人环境中确认其他玩家能看到同步后的开关状态。
